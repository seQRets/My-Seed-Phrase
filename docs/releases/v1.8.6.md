Checks on every change, signed releases, and a clipboard that clears itself in Chrome and Edge. Most of this release is the external review contributed by @deanrie (#1 to #4).

## New

- **Signed releases.** Each release is now built by GitHub and its file is signed, which ties the download to the exact version of the code it was built from. Check it with `gh attestation verify myseedphrase.html -R seQRets/My-Seed-Phrase`. Releases before this one are not signed; for those, the fingerprint below is what there is.
- **The clipboard clears itself in Chrome and Edge.** After you copy a seed, it is cleared 60 seconds later if you stay on the page and copy nothing else. The page never reads the clipboard to check. Safari does not let a page do this, and the warning under the box says so.
- **Printing leaves out every secret.** Print, or "Save as PDF", blanks the seeds, the rolls, the endings, the QR code and the fingerprints.
- **Screen readers announce the result** when you check your words.

## Changed

- Every change to the page is now checked on GitHub as well, with the same checks this page has always been held to.

Nothing about how seeds are made changed.

The built-in self-test still passes 15 of 15.
